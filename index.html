Developer Agreement

1. Content Ownership & Rights
By uploading a game to Pixel Gaunt, you declare that you possess the necessary rights and permissions for all source code, assets, audio, and visual elements included in the project.

2. Prohibited Content
Developers are strictly forbidden from uploading malicious code (malware, miners, phishing scripts), highly offensive material, or games containing unmoderated illicit content. Pixel Gaunt reserves the right to terminate entries violating these rules.

3. Single-File / Packaged Requirements
All projects must be self-contained. For HTML5 games, ensure your index.html correctly paths relative assets, or use inline Base64 where possible to adhere to storage limits.

4. AI Generative Disclosures
If your game logic or art is heavily generated via AI (e.g., Gemini, ChatGPT, Midjourney), we encourage providing the AI prompt block to help the learning community.

Project Details & Guidelines

Pixel Gaunt supports standard Web Technologies. You can deploy games built with HTML5 Canvas, Three.js, Vanilla JavaScript, or exported web builds from engines like Unity/Godot.

🟢 Free Developer Tier

Perfect for lightweight retro clones and single-file HTML5 concepts.

  • Maximum file size per game: 10 MB
  • Format: Single .html file or .zip containing index.html
  • Basic analytics & generic game listing.

🟣 Pro Subscription Tier

Designed for full-scale 3D experiences, high-res audio, and complex assets.

  • Maximum file size per game: 100 MB
  • Format: Complete .zip package directory
  • Priority listing, AI Prompt locking, and detailed engagement analytics.
